What is Dijkstra's Algorithm in Computer Networks?

Routing & Shortest Path First (SPF)

Routing is the process of selecting paths across a network to deliver packets from a sender to a receiver. In packet-switched networks (Layer 3), finding the Shortest Path minimizes propagation delay, packet loss, and link saturation by selecting paths with minimum accumulated link metrics (bandwidth, delay, reliability).

Routers & The OSI Network Layer (Layer 3)

A Router is an OSI Layer 3 device that inspects destination IP addresses and forwards packets using its internal Routing Table. Routers run routing protocols (like OSPF) to dynamically share topology maps (Link-State Advertisements) and calculate optimum next hops.

OSPF Protocol (Open Shortest Path First)

OSPF is an interior gateway protocol (IGP) built directly on Dijkstra's SPF algorithm. Each OSPF router constructs a complete identical link-state database (LSDB) of the autonomous system and executes Dijkstra's algorithm with itself as the root to build the shortest-path forwarding tree.
OSPF Link Cost = Reference Bandwidth (100 Mbps) / Link Bandwidth

Step-by-Step Dijkstra Algorithm Execution

  1. Initialization: Set distance to source $d(source) = 0$, and for all other nodes $v$, $d(v) = \infty$. Mark all nodes unvisited.
  2. Select Minimum Node: From unvisited set, select node $u$ with minimum distance $d(u)$.
  3. Relaxation: For each unvisited neighbor $v$ of $u$, update:
    if (d[u] + weight(u, v) < d[v]) { d[v] = d[u] + weight(u, v); prev[v] = u; }
  4. Mark Visited: Move $u$ from unvisited to visited set. Visited nodes are never re-evaluated.
  5. Termination: Repeat until destination is visited or all reachable nodes are processed.
Time Complexity
O((V + E) log V) with Min-Heap / Priority Queue;
O(V²) with simple Adjacency Matrix.
Space Complexity
O(V + E) to store network graph adjacency list, distance array, and predecessor mapping.
Real-World Protocols
OSPF (RFC 2328), IS-IS (Intermediate System to Intermediate System), Google Maps routing, CDN traffic engineering.
Key Viva Question
Why doesn't Dijkstra work with negative weights? Greedy assumption assumes once a node is visited, its shortest distance is finalized. For negative cycles, use Bellman-Ford.
